# Customer Churn Prediction

This project aims to predict customer churn in the
telecommunications industry using Machine Learning.

The goal is to identify factors associated with
customer churn and help businesses improve
customer retention.

## Business Problem

1. Do customers with month-to-month contracts churn more
   than customers with one-year or two-year contracts?

2. Are customers with shorter tenure more likely to churn?

3. Are higher monthly charges associated with higher churn?

4. Does the type of internet service affect customer churn?

5. Do customers with technical support churn less frequently?
